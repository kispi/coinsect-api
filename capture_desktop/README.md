# capture_desktop

가정용 IP에서 유튜브 라이브 프레임을 떠서 서버로 보내는 클라이언트.

운영 서버(EC2)의 IP는 유튜브가 봇으로 차단해 `yt-dlp`가 라이브 주소를 해석하지 못한다.
그래서 이 부분만 집에서 돌린다. 여기서 하는 일은 캡처와 전송뿐이고,
포지션 인식(Gemini)과 판정은 전부 서버에 있다.

집은 NAT 뒤에 있으므로 서버가 집을 부르지 않는다. **집이 주기적으로 서버를 부른다.**

## 준비물

- Node.js 22 이상 (`--env-file`과 전역 `fetch`를 쓴다)
- `yt-dlp`, `ffmpeg` — PATH에 있거나 `.env`에 경로 지정

의존성 설치는 필요 없다. `node_modules`가 없다.

## 실행

```bash
cp .env.sample .env   # DESKTOP_SECRET을 서버 .env와 같은 값으로 채운다
npm start
```

켜두고 출근하면 된다. 꺼져 있으면 제보가 안 올 뿐 서버는 멀쩡하고,
어드민의 수동 업로드 경로도 그대로 살아 있다.

`yt-dlp`는 유튜브 변경에 맞춰 자주 갱신해야 하므로 가끔 `yt-dlp -U` 해준다.
